# PASSMATE 방문 분석 운영

## 구현과 활성화 상태

관리자 `방문 분석`은 GA4 집계를 서버에서 읽는다. 공개 페이지 측정은 기본 비활성화이며, 이 문서의 연결·개인정보 안내·실측 확인을 마친 뒤 활성화한다. 코드 구현, 관리자 보고서 연결, 실제 방문 측정은 별도의 완료 항목이다.

현재 지원 이벤트: 공개 페이지 조회, 종목 보기, 새 풀이 시작, 새 풀이 완료. 가입 성공은 현재 인증 흐름에서 신규 가입을 확실히 구분할 수 없어 **측정 미지원**이다. 로그인이나 가입 버튼 클릭을 가입 성공으로 세지 않는다. 결과 재방문·이미 제출된 시도는 새 완료가 아니다. 페이지 새로고침으로 풀이 방식이 사라지면 방식 값을 추정하지 않는다.

시작 전 방문 기록은 복원할 수 없다. GA4 표준 보고서는 반영 지연이 있을 수 있으며, ‘실제 0’, ‘아직 수집 없음’, ‘연결 전’, ‘조회 실패’, ‘이전 캐시’는 각각 구분한다.

## 연결 순서

1. PASSMATE 대상 GA4 속성과 웹 스트림을 확인한다. 다른 앱의 속성은 혼합하지 않는다. 시간대와 국가 설정을 실제 화면에서 확인하고 서버 설정도 맞춘다.
2. GA4 광고 기능·Google Signals·광고 개인화를 끈다. 향상된 측정의 자동 페이지/히스토리/스크롤/폼/외부 링크 측정도 끈다. 앱은 정제한 수동 페이지뷰와 표준 참여 시간만 사용한다.
3. Google Analytics Data API를 사용할 프로젝트와 조회용 서비스 계정을 준비한다. GA4 대상 속성에만 Viewer 권한을 부여하며, Google Cloud 전체 관리자 권한을 부여하지 않는다. 새 권한·지속 자격 증명 생성·약관은 실제 작업 직전에 확인한다.
4. 이벤트 범위 커스텀 정의를 등록한다: `qualification_slug`, `learning_method`, `qualification_field`, `qualification_grade`, `question_count_bucket`. 현재 종목 필터는 slug와 공개 경로를 사용한다. 정의가 보고서 메타데이터에 나타난 후 준비 플래그를 켠다. 새 정의의 과거 데이터를 소급 복구하지 않는다.
5. 캐시 마이그레이션과 `admin-analytics` 함수를 배포한다. 플랫폼 JWT 검증을 켜고, 함수 내부에서도 사용자 인증과 DB의 관리자 role을 검사한다. 캐시는 service_role만 읽고 쓸 수 있다.
6. 서버 연결을 확인한 뒤 실제 보관 설정에 맞춘 분석 안내를 확정한다. 검토용 초안은 `docs/ANALYTICS_PRIVACY_DRAFT.md`이며 전체 개인정보 처리방침을 대체하지 않는다.
7. 테스트 속성 또는 디버그/내부 트래픽 구분으로 동의·경로·이벤트를 실측한다. 운영 안내를 게시한 뒤 공개 측정 플래그를 켜고 실제 측정 시작일을 기록한다.

## 환경 설정

| 위치 | 이름 | 값·원칙 |
| --- | --- | --- |
| Vercel 공개 빌드 설정 | `NEXT_PUBLIC_GA4_MEASUREMENT_ID` | 확인한 웹 스트림의 공개 `G-...` ID |
| Vercel 공개 빌드 설정 | `NEXT_PUBLIC_ANALYTICS_ENABLED` | 기본 false, 실측 준비 후 true |
| Vercel 공개 빌드 설정 | `NEXT_PUBLIC_ANALYTICS_NOTICE_READY` | 실제 안내 확정·게시 전 false |
| Supabase Edge secrets | `PASSMATE_ANALYTICS_REPORTS_ENABLED` | 기본 false, 조회 연결 검증 후 true |
| Supabase Edge secrets | `GA4_PROPERTY_ID` | 대상 속성의 숫자 ID |
| Supabase Edge secrets | `GA4_SERVICE_ACCOUNT_JSON` | 서버 전용 읽기 계정 키. 저장소·브라우저·보고서·로그에 출력 금지 |
| Supabase Edge secrets | `GA4_PROPERTY_TIMEZONE` | 실제 속성과 동일하게 설정, 기본 Asia/Seoul |
| Supabase Edge secrets | `GA4_MEASUREMENT_STARTED_AT` | 실제 운영 수집 시작 ISO 시각. 준비 날짜를 임의로 입력하지 않음 |
| Supabase Edge secrets | `GA4_CUSTOM_DIMENSIONS_READY` | 해당 정의가 실제 메타데이터에 나타난 뒤 true |
| Supabase Edge secrets | `GA4_SIGNUP_SUPPORTED` | 현재 false. 검증된 신규 가입 이벤트를 구현하기 전 변경 금지 |

공개 값 변경은 새 웹 배포가 필요하다. 서버 자격 증명은 Supabase의 보호된 secret 설정에만 넣는다. 개인 Google 로그인 토큰을 운영 보고서용으로 재사용하지 않는다.

## 지표와 필터

- 방문자: GA4 totalUsers. 페이지별 방문자를 더해 전체 방문자라고 표시하지 않는다.
- 세션: 재방문을 포함한 방문 단위. 참여 시간은 userEngagementDuration / sessions이며, 세션이 0이면 ‘—’다.
- 학습 단계: 종목 보기·풀이 시작·완료 이벤트 횟수 비교다. 순서를 검증한 퍼널이나 개인별 학습 기록이 아니다.
- 최근 방문: 최근 30분 활성 사용자. 정확한 동시 접속자 수가 아니며 기간·유입·종목·기기 필터는 적용하지 않는다.
- 위치: 국가·도시의 대략적인 집계. GPS나 개인별 위치 정보가 아니다.
- 기간: 7/30/90일 또는 최대 90일 지정. 속성 시간대의 오늘까지 선택한다. 오늘 숫자는 갱신 중임을 표시한다.
- 표와 CSV: 상위 100개 집계 항목. 전체 합계는 별도 보고서로 조회하며 상위 행의 합계로 대체하지 않는다.

일반 보고서는 15분, 실시간은 60초 캐시한다. 조회 실패 시 이전 캐시에는 마지막 성공 시각과 실패를 표시한다. 임계값·기타 행·지원하지 않는 조합도 숨기지 않는다. 브라우저 차단·동의·리퍼러 정책·보고서 지연 때문에 일부 방문은 누락되거나 ‘알 수 없음’으로 나타날 수 있다.

## 수집 범위

허용 경로는 홈페이지, 문제은행, 공개 카탈로그 종목 소개와 정제한 문제풀이 경로다. 실제 시험 시도 ID는 URL에서 제거한다. 관리자·계정·인증 콜백·API·오답 노트·북마크·개인 이력은 측정하지 않는다.

이름·이메일·회원 ID·원점수·선택 답안·문항 본문·메모·인증값을 전송하지 않는다. 리퍼러는 출처 도메인으로 줄이고, 일반 쿼리·해시를 버린다. UTM은 짧은 캠페인 토큰만 사용하며 이메일·전화·자유 입력값을 캠페인 이름에 넣지 않는다. 분석 선택과 완료 중복 방지용 브라우저 저장값은 기존 학습 데이터와 분리한다.

## 실측 체크리스트

- [ ] 동의 전·거절 후 Google 분석 요청 0건.
- [ ] 비공개 화면 이동·동의 철회 중 태그 로드 경합에서도 새 요청 없음.
- [ ] 공개 SPA 이동마다 정제한 페이지뷰 1회, 주소·리퍼러·자동 참여 이벤트의 민감값 없음.
- [ ] 저장 실패 시 학습 성공 없음, 정상 새 풀이/완료 1회, 오래된 결과 재방문은 완료 없음.
- [ ] 실제 GA4 DebugView/Realtime에서 안전한 이벤트 확인.
- [ ] 표준 보고서 반영 후 동일 기간·필터의 관리자 숫자와 대조.
- [ ] 비로그인·일반 회원의 보고서 접근 차단, 관리자만 성공.
- [ ] 실제 캐시 테이블의 RLS·클라이언트 grant 없음·만료 확인.
- [ ] 모바일·기간·분류·빈 상태·오류·CSV·키보드·동의창 Escape/닫기/포커스 복귀 확인.

## 중단·되돌리기

클라이언트 `NEXT_PUBLIC_ANALYTICS_ENABLED=false`로 재배포하면 공개 측정이 중단된다. 서버 `PASSMATE_ANALYTICS_REPORTS_ENABLED=false`는 관리자 조회를 연결 안내 상태로 바꾼다. 기존 CBT·주문 관리에 영향을 주는 권한 변경이나 데이터 삭제는 필요하지 않다.

기능 커밋을 되돌리되, GA4 Viewer 권한·서비스 계정 키·서버 secrets·커스텀 정의는 따로 관리한다. 키가 더 이상 필요 없으면 권한을 철회하고 공급자의 절차로 폐기한다. 코드 롤백은 GA4에 이미 수집된 데이터를 삭제하지 않는다. 캐시는 집계만 포함하며 만료 후 정리된다.

## 검색 노출 개선에 활용

전기기능사·지게차·무대음향·무대기계·무대조명을 동일 기간으로 비교한다. Search Console의 노출·클릭률과 대시보드 검색 세션·학습 시작을 함께 판단한다. 검색 유입이 높고 풀이 시작이 낮으면 소개·종목 선택·풀이 진입을 개선한다. 실제 수록 기출 범위에 맞는 내용과 내부 링크를 확장한다. 네이버의 수집 요청 완료를 실제 검색 노출 완료로 오인하지 않으며 이미 접수된 주소를 반복 제출하지 않는다.
