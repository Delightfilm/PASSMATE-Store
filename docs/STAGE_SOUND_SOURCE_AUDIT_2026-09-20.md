# 무대음향 3급 공식자료 점검

> 점검일: **2026-09-20**
>
> 범위: 2025·2026 필기시험 문제지/확정답안, 출제기준표·표준교재 정오표, 공연법령

## 판정 기준

- **실파일 확보**: 원본 파일이 로컬에서 확인되어 해시 검증이 가능한 상태
- **공식 게시 확인**: 공식 페이지와 게시 이력은 확인했지만 원본 파일은 보유하지 않은 상태
- **누락**: 원고 검증에 필요한 원본 파일이 로컬에 없는 상태
- **보류**: 사용자 요청에 따라 NAS는 이번 점검에서 확인하지 않은 상태

## 결론

2025·2026 공식 기출과 확정답안은 **실파일 미확보**다. 공식 게시 이력만으로 내용을 추정하거나 원고에 추가하지 않는다. 따라서 Stage Sound V8 출시는 계속 차단한다.

현재 로컬 상태:

- 프로젝트 미러 `sources/`: 파일 없음
- 저장소: 무대음향 기출·답안·원고 원본 없음
- NAS: 미점검
- 기존 상태 문서의 `2016–2024 기출 corpus 기반 분석/원고 존재` 기록: 실파일로 검증되지 않음

## 법령 기준

시험문제 검증은 **시험일 당시 시행본**, 신규 원고의 현행 법규 표기는 **원고 기준일의 현행본**으로 분리한다.

### 2026 필기시험일 기준

[2026 필기시험 안내](https://www.ntok.go.kr/staff/community/notice/detail/234)에 따른 시험일은 2026-05-31이다.

|---|---|

| 공연법 시행규칙 | [시행 2025-04-23, 문화체육관광부령 제597호](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=270871) |

2025 시험일과 당시 시행본의 짝은 이번 점검에서 공식 시행계획 원본을 확보하지 못해 확정하지 않는다.

## 반영 원칙과 다음 조치

1. Mac 로컬과 사용자 보관본에서 공식 원본을 먼저 찾는다. NAS 확인은 사용자가 재개할 때 수행한다.
2. 원본이 없으면 자격검정위원회에 2025·2026 문제지와 확정답안의 열람·이용 가능 범위를 문의한다.
3. 확보 후 원본은 NAS에 보관하고 출처 URL, 취득일, SHA-256, 이용 조건만 저장소에 기록한다.
4. 문제지와 확정답안이 같은 회차로 짝지어지고 시험일 법령까지 매핑된 뒤에만 분석한다.
5. 확보 전에는 문제 문구, 출제 빈도, 문항 수, 정답, 법규 해설을 새로 쓰지 않는다.

문제 원문·도표·이미지는 저장소나 판매 PDF에 무단 재수록하지 않고, 검증된 개념 요약만 새 문장으로 작성한다.
