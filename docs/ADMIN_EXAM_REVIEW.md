# 관리자 시험 화면 문항 검토

2026-10-08. Base main: `1551df18ce75481bd8cae0e582c42670de6cfd64` (PR41).
Branch: `codex/admin-exam-review-browser`. 운영 반영 전 변경 기록.

## 승인된 범위

- 기존 문항 제목 목록을 종목·회차 선택 → 실제 풀이 화면의 전체 문항 검토로 교체한다.
- `QuestionBody`, `QuestionChoiceContent`, `ExamViewSettings`와 CBT CSS를 재사용한다.
- 문항 이전/다음, 60개 단위 번호 패널, 현재 회차 내 검색 이동을 제공한다. 회차에는 연도·회차·날짜를 표시한다.
- 문항 수정은 같은 시험 카드 안에서 열고, 편집/저장/사진 처리 중에는 문항 및 종목·회차 이동을 잠근다.
- 저장에 성공한 문항은 현재 위치에서 갱신한다. 새 데이터 조회의 서버 correction은 오래된 세션 저장본보다 우선한다.
- 검토용 선택 답안은 메모리에만 유지한다. 학습 기록·점수·북마크 저장 및 유료 AI 생성은 하지 않는다.
- 신고 편집의 기존 모달, 저장/검수 완료/감사 로그, 권한·버전·원본 해시 계약은 유지한다.
- NAS 사진 저장 서버의 활성화나 인증키 변경은 이번 변경에 포함하지 않는다.

## 검증 증거와 범위

1. 기존 편집 컴포넌트에 인라인 검증을 추가하고 RED(기존 모달 반환)를 확인한 뒤 embedded 렌더링으로 GREEN을 확인했다.
2. 독립 코드 검토에서 발견한 오래된 세션 저장본 우선 표시를 실제 Picker 회귀 검사로 RED 재현했다. 조회 시점의 저장본 기준선 이후 변경만 덮어쓰도록 수정하고 GREEN을 확인했다.
3. 실제 컴포넌트 회귀 검사: 전체 본문·4/5개 보기, 복수 정답, 검색 및 번호 이동, 메모리 답안 유지, 편집 중 이동 금지, 저장 후 위치 유지, 기존 DB 문항/서버 correction 읽기, 기존 업로드 잠금/이미지 렌더링/AI 캐시 계약.
4. Edge 실제 브라우저에서 임시 개발 전용 QA 화면으로 공개 NAS `b7` 번들을 읽었다. 2002년 1회, 41번 이동·본문 수정·메모리 모의 저장·닫기 후 동일 회차/문항/수정 본문과 수정 버튼 포커스를 확인했다. 운영 수정 API 호출은 하지 않았다.
5. 실제 NAS 2번 이미지 로드 확인(197×157px 원본). 보기 설정의 확대 글자 및 하단 번호 스트립 반영 확인.
6. 360/390/430/1280px 검토/인라인 편집, 확대 글자·사진·하단 번호 배치에서 가로 넘침 0. 검사한 표시 버튼·select·input·summary는 44px 미만 대상 0(정답 체크박스는 44px 라벨 영역으로 제공).
7. 모바일 번호 시트: 60개 표시, 스크롤 잠금/해제, Escape 닫기, 마지막→첫 버튼 및 첫→마지막 Tab 순환, 원래 열기 버튼 포커스 복귀 확인.
8. 임시 `app/editor-review-qa` 두 파일을 제거하고 검증용 서버·탭을 종료했다. 사용자 파일이나 원본 데이터를 삭제하지 않았다. 개발 전용 화면은 커밋/배포하지 않는다.
9. 최종 `npm run build`(전체 `npm run check` + Next.js 최적화·타입 검사·24개 페이지 생성) 종료 코드 0. 새 UI 회귀 검사와 기존 문항/이미지/NAS 서버 계약 검사가 통과했다. 빌드 출력에 임시 QA 경로가 없음을 확인했다. 기존 법률 문서/사업자 전화·응대 시간 미확정 경고 6건은 남아 있으며 이번 UI 변경에서 임의 작성하지 않았다.

검증 화면의 저장은 모의 메모리 저장이다. 실제 관리자 인증 저장·신고 해결 E2E, NAS 사진 업로드/크롭 통합, 실기기 iOS/Safari는 이번 브라우저 검사로 증명되지 않았다. 단위 훅 모형의 effect 재실행 한계는 위 실제 브라우저 포커스 검사로 보완했지만 모든 접근성 동작의 전수 검사는 아니다.
