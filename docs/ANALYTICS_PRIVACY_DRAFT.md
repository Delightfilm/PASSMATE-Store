# 방문 분석 안내 검토용 초안

상태: 게시 전 초안. 이 파일은 사이트의 개인정보 처리방침을 대체하지 않는다. 실제 GA4 속성·보관 설정과 기존 운영자 정보를 확인한 뒤 게시 문안을 확정한다. 현재 공개 측정 플래그는 기본 false다.

## 분석 선택 화면 문안

방문 경로와 페이지 이용 시간을 Google Analytics로 분석해 학습 서비스를 개선합니다. 이름·이메일·답안은 보내지 않으며, 거절해도 모든 학습 기능을 이용할 수 있습니다. 하단 ‘분석 설정’에서 변경할 수 있습니다.

선택: 허용 / 거절. 어느 쪽도 학습 이용을 제한하지 않는다. 동의 전에는 분석 스크립트를 로드하지 않는다. 철회하면 추가 측정을 중단하며, 과거 집계의 자동 삭제로 설명하지 않는다.

## 공개 안내에 반영할 확인된 구현 내용

- 목적: 유입 경로·인기 종목·실제 참여 시간·문제풀이 시작과 완료 집계를 통해 학습 서비스를 개선한다.
- 도구: Google Analytics 4. 광고 기능·Google Signals·광고 개인화·세션 녹화는 사용하지 않는 설정으로 운영한다.
- 수집: 허용한 공개 페이지의 정제된 주소, 출처 도메인, 캠페인 분류, 공개 종목, 풀이 시작·완료 이벤트와 참여 시간. 도구가 제공하는 국가·도시·기기·브라우저는 대략적인 집계다.
- 제외: 이름·이메일·회원 ID·개별 시험 시도 ID·문항 본문·선택 답안·원점수·메모·인증값.
- 선택 변경: 하단 분석 설정에서 변경하며 거절해도 사이트 학습 기능을 이용할 수 있다.
- PASSMATE 내부 저장: 분석 선택·중복 집계 방지를 위한 최소 브라우저 값과 서버 전용 집계 캐시. 방문자 원시 행동 로그를 별도 데이터베이스에 쌓지 않는다.

## 실제 설정 확인 후 확정할 내용

GA4의 실제 데이터 보관 설정, 제공자와 처리 장소에 대한 운영 안내, 개인정보 문의 연락처 및 기존 개인정보 처리방침과의 연결을 확인해야 한다. 사업자 정보·보관 기간·법적 근거를 추정해 게시하지 않는다. 이 확인이 끝나기 전에는 `NEXT_PUBLIC_ANALYTICS_NOTICE_READY`를 true로 바꾸지 않는다.
