# PASSMATE Product Structure v1

> Status: **LOCKED**
>
> PASSMATE 자격증 상품의 기본 패키지 구조. 새 자격증에도 특별한 사유가 없는 한 동일한 구조를 사용한다.

## 1. 판매 상품

고객에게 노출되는 판매 선택지는 **2개만** 유지한다.

### 1.1 핵심요약 패키지 — 기본 출시가 5,900원

구성품:

1. **CORE — 핵심요약**
2. **SHEET — 공식·숫자 치트시트**
3. **CHECK — 시험직전 체크리스트**

권장 파일 구성:

```text
01_CORE_핵심요약.pdf
02_SHEET_공식숫자_치트시트.pdf
03_CHECK_시험직전_체크리스트.pdf
```

대상:
- 이미 한 번 이상 공부한 수험생
- 짧은 기간에 전 범위를 압축 회독하려는 수험생
- 시험 직전 반복 복습용 자료가 필요한 수험생

### 1.2 합격팩 — 기본 출시가 9,900원

구성품:

1. **PASS PACK — 상세 합격교재**
2. **CORE — 핵심요약**
3. **SHEET — 공식·숫자 치트시트**
4. **CHECK — 시험직전 체크리스트**

권장 파일 구성:

```text
01_PASS_PACK_합격교재.pdf
02_CORE_핵심요약.pdf
03_SHEET_공식숫자_치트시트.pdf
04_CHECK_시험직전_체크리스트.pdf
```

대상:
- 처음 공부하는 수험생
- 개념부터 계산, 기출 분석, 예상문제까지 한 번에 공부하려는 수험생
- 핵심요약 패키지 전체도 함께 받고 싶은 수험생

## 2. 구성품 역할

### CORE — 핵심요약

목적: **시험 범위 전체를 빠르게 공부할 수 있는 압축 교재**

포함:
- 시험 구조
- 핵심 개념
- 관련 기출 문항 수
- 최근 출제 회차
- 출제회차
- 공식
- 숫자
- 비교표
- 기출 함정
- TIP
- D-1 / 시험 직전 암기
- 30초 암기

CORE 안에 별도 벼락치기 성격의 마지막 파트를 포함한다.

### SHEET — 공식·숫자 치트시트

목적: **시험 직전 공식과 숫자만 초고속 확인**

원칙:
- 설명 최소화
- 공식/단위/숫자 중심
- 휴대폰에서도 빠르게 읽을 수 있게 구성
- 가능한 짧은 분량 유지

### CHECK — 시험직전 체크리스트

목적: **내가 아직 모르는 항목을 시험 직전에 빠르게 확인**

형식 예:

```text
□ dBu / dBV 기준값을 구분할 수 있다.
□ 전압·음압비 20log / 전력비 10log를 구분할 수 있다.
□ 직렬/병렬 임피던스를 계산할 수 있다.
□ AB / XY / ORTF / MS를 구분할 수 있다.
```

### PASS PACK — 상세 합격교재

목적: **처음 공부하는 사람도 개념부터 문제풀이까지 따라갈 수 있는 본교재**

포함:
- 시험 분석
- 상세 개념
- 출제이력
- 자체 도식
- 공식
- 계산 예제
- 기출 함정
- 예상문제
- 정답/해설
- 최종 암기

## 3. 삭제된 구성

### 별도 CRAM / 벼락치기 PDF

**제작하지 않는다.**

이유:
- CORE 핵심요약과 역할이 지나치게 겹친다.
- 고객이 상품 차이를 이해하기 어려워진다.
- 유지보수해야 할 파생물이 불필요하게 늘어난다.

대신 CORE 마지막에 다음과 같은 초압축 섹션을 포함한다.

- D-1 최종정리
- 시험 직전 10분 암기
- 30초 암기

## 4. 상품 포함 관계

```text
핵심요약 패키지
├─ CORE
├─ SHEET
└─ CHECK

합격팩
├─ PASS PACK
├─ CORE
├─ SHEET
└─ CHECK
```

즉 **합격팩은 핵심요약 패키지 전체 + 상세 합격교재**다.

## 5. 데이터 원칙

모든 상품은 하나의 MASTER에서 파생한다.

```text
기출 SOURCE
    ↓
MASTER
    ↓
├─ CORE
├─ PASS PACK
├─ SHEET
└─ CHECK
```

동일 사실을 각 원고에서 독립적으로 관리하지 않는다.

특히 아래 정보는 MASTER를 기준으로 한다.

- 기출 출제회차
- 관련 기출 문항 수
- 최근 출제 회차
- 공식
- 숫자/단위
- 정답 검증 상태
- 법규 최신성 상태

## 6. 현재 무대음향 3급 적용

상품명:

- PASSMATE 무대음향 3급 핵심요약 패키지
- PASSMATE 무대음향 3급 합격팩

번호 체계:

- 핵심요약: `1-1`, `1-2`, `1-3` …
- 합격팩: `2-1`, `2-2`, `2-3` …

이 구조는 v1 기준으로 고정한다.


## 7. 가격 운영 원칙

5,900원 / 9,900원은 현재 **기본 출시가**이며 코드에 고정하지 않는다.

- 각 판매 SKU의 현재 가격 Source of Truth는 Supabase `products.price_krw`.
- 관리자는 `/admin/` 상품 관리에서 CORE SKU와 PASS SKU 가격을 각각 수정할 수 있다.
- 저장한 새 가격은 **그 이후 생성되는 신규 주문**부터 서버 결제금액에 적용한다.
- 이미 생성된 주문/payment attempt의 금액은 생성 시점 값으로 유지한다.
- 상품 카드, 상품 상세, 장바구니는 브라우저에서 현재 active SKU 가격을 다시 조회한다.
- 실제 결제 직전 `create_direct_checkout()`이 DB의 `price_krw`를 `order_items.unit_price_krw`에 pin하고 주문 총액을 계산한다.
- `payment-start`가 반환한 `amountKrw`만 PortOne `totalAmount`로 사용한다.
- 브라우저 localStorage, URL, 표시용 가격은 실제 결제금액의 Source of Truth가 아니다.
