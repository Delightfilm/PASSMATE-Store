# 무대예술 답안 표시 및 공식시험 운영 배포

2026-10-05 사용자 결정: 가답안과 추정 후보가 달라도 학습 문항으로 제공하며, 두 답안의 종류를 명시한다.

- 기존 격리 8문항을 학습용 DB에 복원한다. 이전 격리 기록과 풀이 기록은 보존한다.
- `가답안 (확정답안 미확보)`는 채점 기준이다.
- `추정 후보 (공식 확정답안 아님)`는 참고 정보다. 채점 기준에 합치지 않는다.
- 불일치 문항은 `답안 불일치 · 채점은 가답안 기준입니다.`로 안내한다.
- 후보가 빈 배열이면 `해당 보기 없음`을 표시한다. 추정을 보류한 문항에는 후보를 만들지 않는다.
- 문제를 풀기 전에는 답안 종류만 표시하고, 즉시 채점 후 또는 결과·해설 확인 때 답안 번호와 추정 근거를 공개한다.
- 공식 확정 복수정답은 인정된 보기 중 하나를 선택하면 정답이다.
- 관리자 정정이 적용된 내용에는 기존 원문 후보를 붙이지 않는다.
- 기존 단일 답안 AI 해설은 불일치 및 공식 복수정답 문항에 제공하지 않는다.

## 데이터 경로

SQLite `question_answer_metadata` 및 `question_accepted_answers`는 가답안/공식 답안만 보관한다.
`question_answer_candidates`는 113개 문항의 추정 후보, 비교 결과, 근거 및 출처를 보관한다.
관리자 번들의 답안 위치는 1부터 시작한다. NAS 학습 번들의 `acceptedAnswers`와 `inferredAnswers`는 0부터 시작한다.
공식 복수정답의 `answer`는 기존 소비자와의 호환을 위한 첫 번째 위치이며, 실제 학습 화면 채점에는 `acceptedAnswers` 전체를 사용한다.

무대예술 학습용 문항은 17,235개이며, 이전 격리 기록 8개는 `restored_at`을 가진 이력으로 남는다.

## 검증과 배포 범위

전체 계약 검사, TypeScript 검사 및 프로덕션 빌드가 통과했다. 실제 무대예술 번들 17,235문항, 후보 113문항, 불일치 8문항, 공식 복수답안 45문항을 검증했다.

운영 전달본은 기존 727종목을 보존하고 11종목을 추가한다. 신규 문항은 무대예술 17,235개, 운전면허 669개, 변호사시험 선택형 150개다. 전체 738종목·15,940회차·1,018,976문항이며 기존 CBTBank 오류 9문항은 계속 제외한다. DB 원본은 1,018,985문항이다.

기존 번들 및 불변 릴리스 경로를 유지하는 NAS 오버레이를 사용한다. `releaseId=2026-10-04-image-choices`는 기존 번들 호환성을 유지하며, `contentRevision=official-candidates-20261005`가 신규 카탈로그를 구분한다. 새 자료만 별도 읽기 전용 볼륨에 배치하고 기존 AI 캐시 경로와 보안 헤더를 보존한다. 긴 공식시험 원본 ID는 20자리 SHA-256 ID로 변환하고 `sourceQuestionId`로 원본을 보존한다.

전달 TAR SHA-256: `0deb5770ae78374c3979e3075b4ee0a97b207ce04e44c2016a17ad27e2859197`.
카탈로그 SHA-256: `285f0c8e094d14dd0abfda9dce1807a87130e013288fb94c858d45a807968356`.

운영 적용 결과는 실제 NAS 검증과 Vercel READY 확인 후 배포 리포트에 기록한다. Supabase 스키마 변경은 없다.
