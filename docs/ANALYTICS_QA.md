## 실제 검증과 한계

분석 정책·동의·비동기 로딩·학습 전환·중복 방지·집계·관리자 화면·인기 시험 계약을 검사하는 테스트 **51/51 통과**. 전체 프로젝트 검사, TypeScript 및 운영 설정을 켠 빌드 **통과**, 정적 경로 28개 생성. 기존 법적 문서/사업자 정보 경고 6개는 해결됐다고 주장하지 않습니다.

최초 독립 검토의 중요 문제를 실패 테스트로 재현하고 수정했습니다. 여기에는 GA 호환성 판정, 초기 로딩 이벤트 누락, 페이지 맥락, 여러 탭 중복 완료, 허위 0 집계, 재방문 구별, 국가 기본 선택과 서버 동시 실행 제한이 포함됩니다. 추가 인기 시험 기능만 별도 검토해 종목 식별자 분리와 회원 식별자 없는 기록 포함을 수정했습니다. 실제 PostgreSQL에서 읽기 전용 가상 자료로 같은 종목의 UUID/NAS 기록 병합, 미식별 회원 제외, 손상된 회차 설정의 안전한 처리 결과를 확인했습니다. 기존 회원 기록을 생성·수정하지 않았습니다.

실제 Edge 브라우저에서 동의 전 Google 요청 0건, 거절 후 태그 0개, 설정창 Escape 후 버튼 포커스 복원을 확인했습니다. 허용 후 태그 응답 200 및 정제된 홈페이지·전기기능사 page_view와 qualification_view 수집 응답 204를 확인했습니다. 실제 GA4 실시간 읽기 API에서 방문자와 이벤트 도착을 확인했습니다. 이는 운영 설정을 사용한 로컬 테스트이며 실제 www 운영 측정 시작과 구별합니다. 기존 카카오 운영 관리자 로그인도 성공했습니다. 새 관리자 화면·모바일·철회·실제 운영 전송과 표준 집계 대조는 배포 후 검증 대상입니다.

설정 누락·오류·미수집 상태를 방문자 0명으로 표시하지 않습니다. GA 표준 집계에는 지연이 있으며 실시간 화면은 별도로 조회합니다. 테스트 이벤트가 이 새 속성에 포함되므로 초기 소량 집계를 실제 방문 추세로 해석하지 않습니다.

## 실제 운영 연결

사용자가 각 작업을 승인한 후 PASSMATE 속성 558708413, 스트림 16121277321, 측정 ID G-MTPQ89V1ZQ를 생성하고 향상된 자동 측정을 껐습니다. 전용 읽기 서비스 계정은 이 속성의 Viewer이며 Cloud 프로젝트 관리 역할은 없습니다. JSON 키는 보호된 Supabase 서버 secret에 저장했고 코드·웹 빌드·공개 보고서에 포함하지 않았습니다. Google Data API 인증, 다섯 사용자 정의 항목, 모든 보고서 요청의 실제 호환성과 조회를 확인했습니다.

보관 설정은 이벤트 2개월/사용자 14개월이며 새 활동 시 사용자 보관 기간 재설정이 켜져 있습니다. 사용자 결정에 따라 GA의 기존 광고 지역 설정은 유지했습니다. 웹 태그에서는 Google Signals와 광고 개인화 신호를 보내지 않습니다. 실제 확인한 쿠키·수집·수탁자·보관 정보는 접힌 방문 분석 상세 고지에 반영했습니다. 전체 개인정보 정책의 법적 충분성을 주장하지 않습니다.

## 롤백 절차

운영 분석 서버와 환경 설정은 적용됐으며 웹 배포는 진행 중입니다. 검토 작업 폴더와 기존 회원·학습·주문 데이터는 보존합니다.

활성화 후 수집을 중단할 때는 웹 `NEXT_PUBLIC_ANALYTICS_ENABLED`를 false로 하고 새 빌드를 배포합니다. 보고서 API는 `PASSMATE_ANALYTICS_REPORTS_ENABLED=false`로 중단합니다. 이미 GA에 전달한 통계는 코드 롤백으로 삭제되지 않습니다. GA 접근 철회나 영구 삭제가 필요하면 실제 설정·권한·삭제 범위를 확인하고 별도로 처리합니다.

웹 문제는 이전 정상 배포 복원 또는 해당 PR 변경 되돌리기로 복구합니다. Edge Function 배포와 DB 마이그레이션은 Git 되돌리기만으로 복구되지 않습니다. 캐시 테이블을 유지하더라도 일반 사용자 권한 차단을 유지하며, 기존 회원·문항·주문 테이블을 변경하거나 삭제하지 않습니다.
