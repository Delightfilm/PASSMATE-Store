## 아직 적용하지 않은 운영 단계

1. 준비된 PASSMATE GA4 웹 스트림 생성과 향상된 자동 측정 끄기: 자동 승인 검토가 정확한 생성/설정 승인 부족으로 차단했습니다. 별도 승인 요청 대기입니다. 직원 규모 답변은 1–10명입니다.
2. 집계 캐시 테이블/RLS와 JWT·관리자 권한 검사 함수 배포: 자동 승인 검토가 정확한 운영 변경 승인 부족으로 차단했습니다. 두 작업은 미적용이며 별도 승인 요청 대기입니다.
3. GA 읽기 전용 보고서 자격 증명·속성 권한, 사용자 정의 측정 항목, 보관/광고 설정을 실제 확인해야 합니다. 새 보안 접근·자격 증명 생성은 해당 단계의 명시적 승인이 필요합니다.
4. 개인정보 안내는 검토용 초안입니다. 확인한 고지와 사용자 선택을 갖춘 뒤 측정 시작 시점을 기록하고 설정을 활성화해야 합니다.
5. 운영 웹 통합/배포, 실제 관리자·일반 사용자·비로그인 권한 검사, 수집 허용/거부·철회 및 보고서 대조를 마쳐야 합니다.

## 롤백 절차

현재 운영에 분석 변경을 적용하지 않아 운영 롤백은 필요하지 않습니다. PR을 통합하지 않으면 현재 운영 웹 상태가 유지됩니다. 검토 작업 폴더와 기존 데이터는 보존합니다.

활성화 후 수집을 중단할 때는 웹 `NEXT_PUBLIC_ANALYTICS_ENABLED`를 false로 하고 새 빌드를 배포합니다. 보고서 API는 `PASSMATE_ANALYTICS_REPORTS_ENABLED=false`로 중단합니다. 이미 GA에 전달한 통계는 코드 롤백으로 삭제되지 않습니다. GA 접근 철회나 영구 삭제가 필요하면 실제 설정·권한·삭제 범위를 확인하고 별도로 처리합니다.

웹 문제는 이전 정상 배포 복원 또는 해당 PR 변경 되돌리기로 복구합니다. Edge Function 배포와 DB 마이그레이션은 Git 되돌리기만으로 복구되지 않습니다. 캐시 테이블을 유지하더라도 일반 사용자 권한 차단을 유지하며, 기존 회원·문항·주문 테이블을 변경하거나 삭제하지 않습니다.
